# 💸 글로벌 N분의 1 자동 상계 정산 시스템 (Global Settlement System)

> **CSV 결제 내역 데이터를 기반으로 참여자별 분담금을 계산하고, 국적별 대표자 수거 방식을 통해 불필요한 해외 송금 횟수를 최소화하는 파이썬(Python) 정산 자동화 프로그램입니다.**

---

## 📌 1. 프로젝트 개요 (Overview)
* **개발 배경:** 다국적(한국·일본) 멤버가 함께한 모임/여행에서 발생하는 복잡한 공동 경비를 수기로 정산할 때 생기는 계산 오류와, 불필요한 다중 해외 송금 수수료 문제를 해결하기 위해 기획했습니다.
* **핵심 목표:** 
  1. 영수증별 실제 참여자(0원 초과)만 필터링한 정확한 1/N 정산
  2. 객체 지향 설계(`OOP`)를 통한 사용자별 정산 상태 및 국적 속성 캡슐화
  3. 국내(KR, JP) 그룹 대표자 우선 상계 로직을 통한 송금 경로 최적화
  4. 부동소수점 반올림 오차(단수 차이) 보정을 통한 **회계적 무결성(오차 0원)** 달성
* **기술 스택:** `Python 3.x`, `Pandas`

---

## ⚙️ 2. 시스템 데이터 흐름 (Architecture)

```text
[CSV 결제 데이터] 
       │
       ▼  (Pandas 전처리 & 집합 연산)
[전체 정산 멤버 확정 및 결제액/분담액 집계]
       │
       ▼  (OOP 객체 매핑)
[Settlement 클래스 생성 (이름, 국적 자동 판별, 초기 잔액 0원)]
       │
       ▼  (상계 계산 & 단수 오차 보정)
[개인별 최종 미수금(+) / 미지급금(-) 산출]
       │
       ▼  (그리디 & 국적별 그룹 매칭)
[국내 대표자 수거 ➔ 국가 간 교차 정산 안내 출력]
```

## 💡 3. 핵심 구현 로직 (Key Features)

### ① 객체 지향 설계 (`class Settlement`)
사용자마다 독립된 정산 계좌(상태)와 국적 정보를 안전하게 관리하기 위해 `Settlement` 클래스를 설계했습니다.
* 이름 길이 기반 국적 자동 매핑 (`len(name) == 3` ➔ `JP`, 그 외 ➔ `KR`)
* `dict`와 `set` 합집합 연산(`|`)을 결합해 결제 내역이 0원인 참여자 누락 방지

```python
class Settlement:
    def __init__(self, name, nationality='KR'):
        self.name = name
        self.balance = 0.0
        self.nationality = nationality
```

### ② 국적별 그룹 대표자 우선 상계 알고리즘
모든 멤버가 개별적으로 해외 송금을 진행하는 비효율을 막기 위해, **같은 국적 내 대표자(`YH`, `YSK`)가 팀원들의 미지급금을 먼저 수거한 뒤 대표자 간 교차 정산**을 진행하도록 설계했습니다.

## 🛠️ 4. 트러블슈팅 (Troubleshooting)

### 🚨 문제: N분의 1 분할 연산 시 부동소수점 반올림으로 인한 5~6원 단수 오차 발생
* **원인 분석:** 영수증 금액을 참여 인원수로 나누는 과정에서 무한 소수점(`float`)이 발생했고, 이를 단순 합산·출력하면서 총 미수금(받을 돈)과 총 미지급금(줄 돈) 사이에 미세한 원 단위 오차와 `.0` 표기 문제가 발생했습니다.
* **해결 방법:** 
  1. 정산 잔액 산출 후 `int(round(obj.balance))`를 적용해 원 단위 정수형으로 표준화했습니다.
  2. 전체 잔액의 총합이 `0`으로 수렴하도록 단수 차액 보정 로직을 적용하여 **총 지출액과 총 정산액의 100% 일치**를 검증했습니다.
* **성과:** 정산 오차를 **5원 ➔ 0원**으로 제거하여 실무 회계 기준에 부합하는 정산 결과 판을 구현했습니다.
