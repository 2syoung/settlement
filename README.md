# 🏛️ 한·일 다자간 여비 정산 및 환리스크 최적화 파이프라인

다국적 멤버(한국인 3명, 일본인 3명) 간의 다자간 비용 정산 프로세스를 효율화하고, 환율 변동성 리스크를 관리하기 위한 데이터 엔지니어링 및 분석 프로젝트

---

## 🎯 1. 프로젝트 개요 & 문제 정의 (Why)
- **비즈니스 페인 포인트 |** 글로벌 여행 및 크로스보더 트랜잭션 증가로 다국적 멤버 간 복잡한 다자간 정산 수요 발생.
- **금융 도메인 한계 |** 일본 금융 마켓 특유의 높은 타행 송금 수수료(건당 150~440엔) 및 카드 결제 시 발생하는 매입 시차(T+2 Lead Time)로 인해 정산 무결성이 깨지고 환리스크 비용이 추가로 발생.
- **해결 방안 |** 다자간 차변/대변 내역을 통합 상계 처리하는 **Netting 알고리즘**과 최적의 정산 시점을 추정하는 **NumPy 기반 시계열 예측 모델**을 결합하여 정산 프로세스 비용을 혁신적으로 절감.


## 🚀 2. 데이터 파이프라인 아키텍처 (How)
- **Extract (수집) |** 데이터 소스 다원화(Multi-sourcing) 전략 적용. 글로벌 외환 매크로 추세는 `yfinance` 라이브러리로 수집하고, 국내 카드 청구 정합성을 위한 최종 고시 환율은 국내 금융 API 링크 연동.
- **Transform (전처리) |** 수집된 원화(KRW) 지출 원장에 결제 수수료율(1.6%)을 선반영한 후 엔화(JPY)로 일괄 데이터 타입을 스위칭(Type Casting)하여 정산의 무결성 확보.
- **Load (저장 & 시각화) |** 정돈된 다자간 정산 잔액 데이터를 `openpyxl`을 활용해 관리회계용 엑셀 장부로 출력하고, Tableau 인터랙티브 대시보드로 연동.


## 🛠️ 3. 핵심 기술 스택 (Tech Stack)
- **Language |** Python 3.x
- **Data Engineering |** Pandas, NumPy, openpyxl, yfinance, requests
- **Visualization |** Tableau Public(매개변수를 이용한 사용자 맞춤형 환율/수수료 시뮬레이터 구현), Matplotlib 
- **Version Control |** Git, GitHub (`.gitignore` 가상환경 인프라 통제 적용)


## 📊 4. 머신러닝 및 최적화 알고리즘
1. **정산 프로세스 최적화 (Netting Rule) |** 다자간 거래를 국적별 허브(Hub) 기점으로 압축하여 송금 횟수 및 수수료 최소화.
2. **시계열 다항 회귀 예측 (Polynomial Regression) |** 3~5년 치 누적 데이터를 기반으로 L2 Loss(최소제곱 오차)를 최소화하는 곡선 방정식을 도출하여 정산 타겟월인 2027년 1월의 최저 환율 시점 시뮬레이션.
